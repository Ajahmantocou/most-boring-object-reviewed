# The Most Boring Object, Reviewed in One Line

An entry for the [The Most Boring Object, Reviewed in One Line](https://make.fun/c/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3) bounty on make.fun.

## The entry

> The eraser fixed every mistake on my exam, then shrank to nothing — the only employee ever fired for doing its job too well.

One line, 124 characters. The object is a pencil eraser: about as boring and everyday as an object gets, a pink nub whose whole existence is fixing other people's mistakes. The joke comes from a detail only an eraser has — it gets smaller every time it works, until there is nothing left of it. So the review treats it as an employee and lets that logic run to its end: the better it does its job, the faster it disappears, and in the end it is "fired for doing its job too well." The turn lands early ("shrank to nothing") and the last words sharpen the joke instead of trailing off — the eraser's own dullness, its slow self-erasure, is the punchline.

## How it works

`main.ts` (Node 22, TypeScript run as-is) deterministically writes the review to `/output/entry.txt`. No network, no secrets, no input — the same line every run.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
